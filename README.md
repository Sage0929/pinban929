# 拼版台

按纸张尺寸排图、一键铺满可打印区域的网页工具，支持活页手帐孔位和折页。

在线使用：**https://pinban929.netlify.app**

整个网站只有一个 `index.html`，不需要安装，也不需要服务器。

---

## 功能

- **纸张**
  - 常用：A3、A4、A5、A6、B5、Letter、Legal
  - 活页手帐：A6per、A6、A7、M5、A5、A5S、B5、A4，以及二折页和三折页
  - 照片纸：5 寸、6 寸、7 寸、8 寸、10 寸
  - 卡片：明信片、名片、TN 等
  - 支持自定义尺寸和横竖向切换
- **图片**
  - 多选添加、拖入或 Ctrl+V 粘贴
  - 拖动移动，会自动吸附边距和相邻图片
  - 拖右下角方块等比缩放，也可以输入精确的毫米数
  - 旋转 90°、复制、删除
  - 证件照尺寸预设：1 寸、2 寸等
- **边距和间距**：四边可分开设置，图片之间的间距单独设置。
- **一键排版**
  - 最大化填满：同比例放大到最大
  - 紧密排列：保持尺寸，放不下自动换页
  - 用一张图铺满整页
- **打孔和折页**
  - 孔位预设按孔心距排布，自动上下居中
  - 孔可放在左边或右边（做双面活页时背面用右边）
  - 排版时自动避开孔区
  - 可选打印孔位圈和折线
- **打印建议**：根据纸张类型列出驱动设置和注意事项，并显示每张图的打印 DPI。
- **输出**：打印、导出 PDF、导出 PNG（200/300/600 DPI）。可选加裁切线。

## 孔位预设（孔心距，单位 mm）

| 预设 | 孔数 | 孔心距 |
|---|---|---|
| A6per | 6 | 19 / 19 / 51 / 19 / 19 |
| A6 标准 | 6 | 19 / 19 / 38 / 19 / 19 |
| A5 / A5S | 6 | 19 / 19 / 70 / 19 / 19 |
| A7 | 6 | 19 × 5 |
| M5 | 5 | 19 × 4 |
| B5 | 9 | 19 / 19 / 51 / 19 / 19 / 51 / 19 / 19 |
| A4 | 4 | 80 × 3 |
| A5 / B5 / A4 多孔 | 20 / 26 / 30 | 9.5 |

不同品牌有 1–2mm 误差，正式打印前建议先用普通纸印一张，套进活页夹核对。

## 使用步骤

1. 选纸张。活页纸会自动套上对应孔位。
2. 设置边距和图片间距。
3. 添加图片。
4. 点「一键排版」，或者手动拖动、缩放。
5. 在「输出」里选纸张类型，然后打印或导出。

打印时，在浏览器打印对话框里设置：

- 缩放：实际大小 / 100%（不要选「适合页面」）
- 边距：无
- 页眉页脚：关闭

## 更新网站

### 方法一：Netlify 拖拽

1. 改好 `index.html`，放进一个文件夹。
2. 登录 Netlify，打开 pinban929 项目，进入 **Deploys** 页面。
3. 把文件夹拖进页面。网址不变。

### 方法二：GitHub 自动部署

Netlify 连接这个仓库后，在 GitHub 上修改并提交 `index.html`，网站会自动更新。

## 修改纸张和孔位

都在 `index.html` 的脚本开头。

**加纸张**：在 `PAPERS` 数组里加一行。

```js
{g:'活页手帐（带孔位）', id:'myPaper', n:'显示名称', w:95, h:170, holes:'A6per', folds:[95]}
```

| 字段 | 说明 |
|---|---|
| `g` | 下拉菜单里的分组名 |
| `id` | 唯一标识，不能重复 |
| `n` | 显示名称 |
| `w`、`h` | 宽和高，单位 mm |
| `holes` | 可选，默认套用的孔位预设 |
| `folds` | 可选，折线距左边的位置 |
| `land: true` | 可选，默认横向 |
| `photo` | 可选，照片纸在驱动里的尺寸名 |

**加孔位**：在 `HOLES` 里加一项。`g` 是相邻孔心之间的距离列表，`d` 是可选的默认孔径。

```js
myHoles:{n:'显示名称', g:[19,19,51,19,19], d:5.5}
```
